# Studying-app

## 概要

学習内容を具体的なタスクに細分化して管理し、
「何を、どこまで学習すれば完了なのか」を意識しながら
学習を進められるようにするWebアプリケーション。

## 開発目的

学習を始める際に、学習する内容と習得完了の条件を明確にし、タスク単位で学習の進捗を管理できるようにする。

## 主な機能

### 学習内容の登録

* 学習する内容を登録する
* 1つの学習内容に複数のタスクを登録できる

### タスク管理

* 登録した学習内容を表示する
* 学習内容に紐づくタスクを表示する
* 未完了タスクと完了タスクを分けて表示する
* タスクを完了状態に変更できる
